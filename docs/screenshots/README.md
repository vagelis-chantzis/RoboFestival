## Capture tips

- Use the same browser zoom for all screenshots (recommended: 100%).
- Keep consistent window width so docs look uniform.
- Prefer dark or light mode consistently across all images.
- Mask or remove any personal data before sharing.
- Save PNG format for clarity.
